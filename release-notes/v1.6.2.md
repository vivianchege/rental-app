# Ruiru Rentals 1.6.2

- Check updates now reports the installed and latest versions when the app is current.
- Available updates show release notes and select the APK that matches the Android version.
- Android downloads the APK in-app and opens the Android installer for user confirmation.
- Android 7–9 and Android 10+ packages now use separate sign-in and target-SDK builds.
- Deleted manager profiles remain as disabled audit tombstones so legacy UID rules cannot restore access.
